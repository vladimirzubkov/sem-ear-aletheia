# Popis semestrální práce

**Téma semestrální práce:**  
Rozvrhování univerzitních kurzů s možností optimalizace a personalizace.

**Krátký popis očekávané funkcionality:**  
Rozvrháři vypisují předměty, učitele zadávají své časové možnosti. Systém vytváří rozvrh a předběžně zapisuje studenty. Studenti si mohou měnit svůj osobní rozvrh podle zbývající volné kapacity v příslušných časových slotech. Studenti a učitele si mohou vypisovat předměty, které mají. Rozvrháři mohou měnit časové sloty a místnosti vypsaných předmětů (CRUD), o změnách budou příslušní učitele a studenti informování (emailem).

**Seznam hlavních funkcí aplikace:**  

- Vytváření základního rozvrhu administrátory s přiřazením kurzů k časovým slotům, místnostem a sekcím.  
- Vstup preferencí vyučujících a studentů pro personalizaci.  
- Optimalizace pro tvrdá omezení (bez kolizí) a měkká (preference, využití zdrojů).  
- Výpočet metrik jako využití místností a spokojenost uživatelů.  
- Integrace solverů pro řešení NP-těžkého problému.

**Komu bude výsledný systém určen:**  
Systém je určen administrátorům univerzity pro automatizaci plánování, vyučujícím pro zadávání preferencí a studentům pro výběr sekcí podle osobních potřeb.


**Poznámka:** můj semestrální projekt a bakalářská práce bude souviset s tvorbou rozvrhu.
